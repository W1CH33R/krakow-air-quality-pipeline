# Collaboration rules

Communicate with the user in Polish. Explain decisions, completed work, and errors in Polish. Accept instructions in Polish.

Keep all published project content in English. This includes every README.md, documentation, docstrings, code comments, identifiers, module names, application messages, logs, and interface text. Write commit messages, pull requests, issues, and their descriptions in English.

Follow professional Python and data engineering practices. Prefer readable, necessary code and a simple architecture. Avoid marketing language. Test the implementation and clearly report anything that could not be verified. Never fabricate measurements, statistics, test results, benchmark figures, screenshots, or commit history. Never present synthetic test fixtures as real data.

Omit AI authorship statements unless a license, terms, or another applicable rule requires disclosure. Preserve required AI disclosures.

Never commit credentials, API keys, or local environment files. Obtain explicit user approval before committing, pushing, or publishing to GitHub. Keep work within this project.
